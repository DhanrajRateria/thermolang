# Contributing to ThermoLang

Thank you for your interest in contributing to ThermoLang! We are excited to build a community around this project.

## How to Contribute

1.  **Find an Issue:** Look through the open issues to find something to work on. If you have a new idea, please open an issue first to discuss it.
2.  **Fork the Repository:** Create your own fork of the ThermoLang repository.
3.  **Create a Branch:** Create a new branch for your feature or bug fix.
4.  **Write Code:** Implement your changes, ensuring you follow the project's coding style.
5.  **Add Tests:** All new features must be accompanied by unit tests.
6.  **Update Documentation:** If you change any public-facing API or language feature, please update the relevant documentation in the `/docs` directory.
7.  **Submit a Pull Request:** Push your changes to your fork and submit a pull request to the `main` branch of the official repository.

## Coding Style

*   We use a style similar to the Google C++ Style Guide.
*   Use `snake_case` for variables and functions.
*   Use `PascalCase` for classes and structs.
*   Use comments to explain complex logic.

We look forward to your contributions!
